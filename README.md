# ЛК клиента — локальная копия под вымышленный бренд High Standards LTD

Локальная самодостаточная копия клиентского кабинета (bp-client) с машины сборки КП, переодетая под вымышленную компанию. Источник — рабочие копии `bp-admin/` и `bp-client/` на 09.10.2026. Опубликована на GitHub Pages: **<https://ivanmetel.github.io/highstandards-bp-client/>** (репо `ivanmetel/highstandards-bp-client`).

**Локальный запуск:** в этой папке `python3 -m http.server 8791` → <http://localhost:8791/>

- бренд High Standards LTD, лого `my_logo-removebg.png`, вымышленные менеджер и контакты (Андреас Николау / Andreas Nikolaou, +357 99 452118, info@highstandards.com.cy);
- план этажа — две фото плана (`fl1.png`, `fl2.png`): ряд по левому краю, суммарно 2/3 ширины полосы, подпись "План помещения"; секция "Фото объекта" и галерея внизу убраны (photos: [], gallery: []);
- фото справа от описания убрано (текст на всю ширину);
- строка "Материалы и транспорт" убрана (field_material: "");
- зона работ — кухня-зал, спальня ×2, санузел;
- пакетный состав работ — 10 крупных позиций + 2 сопутствующие, итог таблицы 108 000,00 €, черновые материалы 12 000 € → стоимость 120 000,00 € + 19% VAT (в блоке цены: включая работы и черновые материалы); срок 7–8 месяцев;
- рабочий тумблер RU/EN: словарь FIXED и манифест переключаются целиком (setLang в data.js), выбор запоминается в localStorage, печать идёт на активном языке.

## Файлы

| Файл | Назначение |
|:--|:--|
| `index.html` | каркас кабинета: бренд, тумблер RU/EN, двуязычный хром |
| `client.css` | стили кабинета + правила видимости языковых надписей |
| `client.js` | загрузка локальных engine/data/published, тумблер RU/EN |
| `engine.js` | движок сборки: тексты вынесены в словарь FIXED, chooser помещений — только при наличии помещений |
| `data.js` | словари STRINGS_RU/STRINGS_EN, строки сметы RU/EN, манифесты RU/EN |
| `document.css` | форма документа (копия + стили доп. фото плана) |
| `published.json` | опубликованное состояние: manifest (RU) + manifest_en |

Все данные вымышлены: объект, суммы, участники и контакты не существуют.
